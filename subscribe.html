订阅更新

新文章发布后怎么收到通知 —— 三种方式，都不需要注册本站账号。

① RSS / Atom（推荐）

把下面的地址加到任意 RSS 阅读器里，有新文章就会自动出现在订阅列表。RSS 是开放标准，不绑定平台，也不用留邮箱。

https://grp.blacknet.cc.cd/feed.xml 查看源
  1. 复制上面的地址。
  2. 打开你常用的阅读器（Feedly、Inoreader、NetNewsWire、Reeder、FreshRSS…），选「添加订阅源 / Add feed」。
  3. 粘贴地址，确认。之后每次更新都会自动推送，无需再来本站。

源里带全文摘要与原文链接，正文始终以站内为准。当前更新频率取决于投稿量，不做固定节奏承诺。

② 关注 GitHub 讨论区

内容本身存放在开源仓库的 Discussions 里。在仓库页面点 Watch → Custom → Discussions，新讨论会直接进你的 GitHub 通知。

  • 仓库Chengxidaxia/GroupBlackNet
  • 讨论区Discussions
  • 适合已经在用 GitHub 的人；能收到评论回复与被 @ 的提醒

③ 邮件

本站不收集邮箱、也不发营销邮件。之前首页那个「每周一封精选信」的订阅框是个没有接通的占位，已经撤掉 —— 与其收下你的邮箱却发不出信，不如直接说清楚：目前没有邮件订阅。

如果你确实希望有邮件通知，或者想单独沟通，请直接发信到 chengxidaxia@outlook.com。收到足够多的需求后，可能会接入第三方邮件服务（如 Buttondown）；在那之前，RSS 是唯一稳定的推送渠道。
